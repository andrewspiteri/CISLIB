# Maintenance and contributions

Andrew Spiteri maintains the official CisLib repository. Changes and publication
are managed by the maintainer; external issues, pull requests and discussions are
not accepted at this time.

The project is open source under the [MIT License](LICENSE.md). You may use, copy,
modify and redistribute the software under that licence. Those rights do not
grant write access to the official repository.

CisLib is in development. Source availability does not imply a qualified package
release or completion of the outstanding verification and release work.
