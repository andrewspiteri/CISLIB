The unit and fresh-process test families share the concrete fixtures; their assertions are backed by independent native Python readers. A new structured mode closes the combined direct-Core equivalence gap without adding a shipping type. Native readers compare parsed JSON types recursively, including bool/int and int/float distinctions; they do not infer a source LogValue kind when two kinds encode identical numeric text. C# JsonNode value comparison is less strict for numerically equal values. Only separately captured timestamps are excluded from pair equivalence, after each timestamp passes exact UTC shape and calendar validation. Private data in supplied Exception.Data is excluded in both paths. Corruption controls remove or change representative fields and must fail for the intended reason.

No-output, saturation and writer-fault cases use actual internal queues with controlled callbacks and memory bytes. Other native cases use public runtime creation and real JSONL files. This does not claim operating-system failure injection or a LoggerFactory/host-composed exception contract. Native readers use the retained Windows Python 3.12 and Ubuntu Python 3.12 lanes. Native consumers require exact .NET 10.0.12 with roll-forward disabled and the retained assembly identities.
