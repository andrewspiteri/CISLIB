WP04-S01-T01/T02/T03 implement CIS.Logging.LogValue and the fixed LogValueKind numbers from the [reference specification](../../../implementations/csharp/verification/contracts/startup/EventSurface.cs). Eleven factories create real immutable values: Null(), Boolean(bool), String(string), Number(double), Integer(long), IntegerString(string), DecimalString(string), Uuid(Guid), Timestamp(DateTimeOffset), Array(IEnumerable<LogValue>) and Map(IReadOnlyDictionary<string, LogValue>). Public properties expose Kind and IsTruncated; payload storage stays internal. UUID/timestamp factories retain the specified kind numbers and store their normalized text immutably.

Uuid(Guid) emits lowercase hyphenated 8-4-4-4-12 text. Guid.Empty and arbitrary UUID bit patterns are valid attribute values; the startup instance identifier has separate stricter requirements. Timestamp(DateTimeOffset) converts the supplied offset to the same UTC instant and emits invariant yyyy-MM-dd'T'HH:mm:ss.fffffff'Z' text, including exactly seven fractional digits. Neither kind becomes String merely because its wire representation is a JSON string.

```csharp
using CIS.Logging;

LogValue id = LogValue.Uuid(Guid.Parse("5FBAB327-67AB-47D1-B814-B3A98C16E41F"));
LogValue at = LogValue.Timestamp(
    new DateTimeOffset(2026, 10, 11, 1, 2, 3, TimeSpan.FromHours(2)).AddTicks(1234567));
```

The stored text is 5fbab327-67ab-47d1-b814-b3a98c16e41f and 2026-10-10T23:02:03.1234567Z respectively. The API accepts explicitly typed values and owned LogValue containers; there is no object/generic factory, reflection serializer or arbitrary-object ToString conversion. A byte array, exception, function or dictionary of arbitrary objects needs an explicit caller-selected supported representation. Ordinary language conversions performed by callers before invoking a typed factory lie outside this boundary.

Integer accepts inclusive Â±9007199254740991 and rejects every larger magnitude, including native long extrema. Number accepts every finite double, preserves its IEEE value and keeps Number even for whole values or magnitudes above the integer boundary. NaN and either infinity fail with ArgumentOutOfRangeException. IntegerString accepts canonical signed ASCII base-10 text of any magnitude, excluding leading zeros, plus/exponent/whitespace and negative zero. DecimalString requires an invariant fractional part, preserves arbitrary precision/trailing zeros and permits negative decimal zero. No numeric constructor changes to a string based on magnitude, and neither numeric-string factory parses through double/decimal.

String preserves valid Unicode scalar text, including whitespace and controls, while rejecting malformed UTF-16. Maps preserve key text and compare ordinally: case variants, composed/decomposed sequences and whitespace keys remain distinct. Keys require 1â€“255 scalars without Unicode controls or malformed UTF-16. Duplicate enumeration keys and null child references are rejected; use LogValue.Null() for explicit null. Arrays preserve order. Both collection factories enumerate/copy their caller containers, and safely share already immutable child LogValues. Mutating original nested dictionaries/lists cannot change the result; even internal read-only views reject mutation.

Required null arguments use ArgumentNullException with value/items/properties. Malformed text, numeric strings, keys and child references use ArgumentException; unsafe integers/nonfinite numbers use ArgumentOutOfRangeException. Fixed explanations and null ActualValue avoid echoing the rejected scalar/key. These constructor errors precede the later runtime capture error and InvalidEvent accounting.

Each collection factory treats its new root as depth 1 and node 1, retaining at most depth 8 and 1024 value nodes. Keys do not count as nodes. A repeated immutable child counts on every containment occurrence. Exact boundaries retain complete content and keep IsTruncated false; excess children are omitted while map/array shape and retained scalar types stay intact. A partially fitting descendant is recursively projected, without mutating its source. Already owned immutable subtrees may be shared when their cached shape fits; caller containers are always copied.

Structural projection keeps the caller's enumeration prefix. It reads at most 1024 root entries, including one lookahead when 1023 scalar children exhaust the budget, and disposes enumerators on completion, validation failure or truncation. It does not inspect caller Count/Keys/lookups or sort/materialize an oversized map to select its globally lowest keys. Retained map keys compare ordinally; the later encoded-entry allocation orders those retained keys ordinally. This distinction is a prepublication implementation choice needed to combine bounded copying with the declared interface.

Invalid keys, duplicates and null child references encountered in the inspected prefix, including the first excess entry, remain argument errors. The omitted suffix is not enumerated or validated. Caller enumerators must cooperate: their own blocking, recursion or exceptions cannot be given a wall-clock guarantee by these synchronous factories. Normal supported API construction cannot create a cycle: LogValue is sealed, containers are owned and there are no mutable payload setters/object conversion paths. Unsafe reflection-created graphs are outside the supported input surface.

IsTruncated propagates both newly omitted content and prior descendant/root loss, even when a later projection loses nothing further. Empty containers remain distinct from explicit null and do not imply loss on their own. Later scope/event merging must carry the captured root's loss flag independently if overrides remove marked children. Per-root budgets are private instances; simultaneous constructions cannot consume each other's allowance.

String/key/identity checks now share the internal CIS.Text.UnicodeScalarText decoder. Policies remain distinct: string values permit controls/empty text, keys permit whitespace but require 1â€“255 control-free scalars, and identities require nonblank text with their selected limit. Malformed UTF-16 remains invalid, including after a large valid prefix. Attribute string/numeric-string storage remains immutable input representation; configured aggregate entry-byte projection and actual encoded output remain later capture/rendering work. The startup snapshot already resolves the user's configurable default 64 KiB cap. This task does not claim a logger or a bounded emitted record.
