# Caller cancellation and bounded disposal

WP05-S10-T03 adds IAsyncDisposable to CoreLogRuntime. DisposeAsync directly wraps StopAsync(CancellationToken.None), so it starts shutdown if needed and otherwise joins the original shared task. It adds no disposal state, timer, drain window or output reopening. Repeated disposal waits on the same operation.

StopAsync's CancellationToken belongs only to that caller's wait. An already-cancelled first caller still closes admission and starts shutdown before its wait cancels. Cancelling later callers does not cancel the operation or the output-owned I/O token. Uncancelled stop callers and disposal callers can still observe completion at the original deadline. Even after the shared task completed, an already-cancelled caller receives cancellation with its original token.

DisposeAsync does not return the stop result. GetDiagnostics().LastStopResult retains the original immutable outcome, including unsuccessful or pending delivery. At expiry, disposal can finish while actual I/O/cleanup remains pending. The existing worker retains ownership until I/O settles; full primary-error/cleanup-error preservation and eventual release remain T04. Public creation remains part of the following lifecycle completion; no placeholder factory is added here.

Eight barrier-driven cases use the actual configured runtime and its output-owned cancellation token. The pre-cancelled case observes closed admission, a shutdown timestamp, Stopping state, a Stopped write and the original deadline before any later stop/dispose call can initiate shutdown instead. Uncancelled callers receive the shared task directly. Sixty-four disposal joins share task identity; sixty-four independently cancelled callers preserve token identity without reaching output cancellation. A 9 ms advance followed by later disposal calls and the last 1 ms proves no new drain window for the frozen 10 ms operation. Late I/O leaves the cached result unchanged. Empty, disposal-first, stop-first, pre-cancelled, later-cancelled and already-completed cases are separate observations. These controlled cases do not substitute for T05's full physical/process race qualification.
