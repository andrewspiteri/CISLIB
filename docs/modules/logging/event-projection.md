ApplicationName, EnvironmentName and ServiceVersion project to service/env/version. Resource is an explicit fourteen-field allowlist: build_version, instance_id, initialized_at, environment_kind, os_family, and available process_started_at, host_name, os_description, os_architecture, process_architecture, runtime_description, process_id, commit_id and build_id. The first five are required. Unavailable optional facts are omitted; process_id remains an integer and resource timestamps use the typed UTC timestamp factory. Configuration, destinations, paths and arbitrary environment data never become metadata. Captured initialization/process-start facts are separate from the event instant added by T03.

The six emitted severity tokens are trace/debug/info/warn/error/critical. None creates no facts and does not examine source arguments; undefined native enum values fail before payload access. Emitted levels require nonnull snapshot/scope/data, a component and event name of 1–255 valid Unicode scalars without controls, and a nonnull message. Empty messages/templates are retained; null templates are absent. Required names preserve supplied text; optional operation identifiers are trimmed, blank falls back to the captured scope, and invalid/oversized identifiers fail without clipping.

Message/template strings preserve supplied text within 8192 Unicode scalars and otherwise retain a scalar-safe prefix with loss recorded. Supplied malformed Unicode remains invalid, including a suffix beyond that bound. Existing exception projection separately validates only its retained bounded prefix. Attributes are copied through actual LogValue.Map; immutable typed children may be shared. Scope attributes merge before explicit attributes and matching ordinal keys are replaced as complete values. The candidate map retains at most 1023 distinct keys at first encounter while still resolving later duplicates, then applies its independent root-inclusive 1024-node/depth-8 projection. Omitted new keys stay omitted; native captured enumeration order is not a portable ordering contract. Prior scope/attribute loss survives replacement, and exception/message/template loss reaches the event marker. Detailed event precedence/reserved-field qualification follows in T02.

Callers must not concurrently mutate the DTO or its collections during capture. Caller enumeration and exception accessors must cooperate; their cost, exceptions and deliberate side effects are not hidden. Captured named references and the supplied immutable scope view remain stable, but this does not promise an atomic snapshot of concurrently changing caller objects. Native exception diagnostics are separate from portable field semantics.
