# Microsoft structured state

The provider keeps the supplied formatter as the only message formatter. It passes the original state and exception to that formatter after Core's interest check. State implementing IEnumerable<KeyValuePair<string, object?>> is copied as ordinal attributes. Other state remains formatter input only. The exact {OriginalFormat} key supplies message_template when its value is a string; null means absent. It is excluded from attributes. Core clips template text at its existing scalar and aggregate entry bounds; the provider does not parse it.

Normalization runs synchronously inside Core capture after Activity IDs and the event clock have been captured. The internal LogEventData capture callback returns an owned template/map and never reaches an output queue. Caller collection/normalization failures become Core InvalidEvent accounting, without partial admission. Public frontend runtimes also contain recoverable supplied formatter failures before state capture; the formatter remains on the caller. Internal output-only qualification retains its historical propagation behavior. This private seam adds no public member, dependency or general serialization framework.

Supported values are null, Boolean, string/char, SByte, Byte, Int16, UInt16, Int32, UInt32, Int64 and UInt64 within the portable safe-integer range, finite Single/Double, Decimal, Guid, DateTimeOffset, UTC DateTime, and explicit immutable LogValue values. Integral magnitudes never change a number to a string; use LogValue.IntegerString explicitly for larger integers. Decimal uses invariant decimal-string form, including .0 for whole values. Timestamps are converted to UTC through the existing value factory; non-UTC DateTime is rejected instead of guessing an offset. Single is widened exactly to Double: 0.1f becomes 0.10000000149011612 in the numeric attribute even if the formatter displays 0.1. Enums, TimeSpan, Uri, IPAddress, native integers, Int128/UInt128, BigInteger, arbitrary objects and nonfinite numbers are rejected. No arbitrary ToString or reflection serialization is used.

Nested arrays/enumerables and maps are copied recursively. Nested maps accept string-key IDictionary or IEnumerable<KeyValuePair<string, object?>> forms. A root Dictionary<string, int> does not implement the supported root state shape and remains formatter input only; it can be copied as a nested map. Keys keep their ordinal casing and follow Core's Unicode/control/length rules. Last visited duplicate keys win. The provider supplies event_id before copying and ignores any state value for that key, so state or typed scope cannot replace its numeric input. Ordinary attribute projection still follows Core's aggregate truncation rules; numeric ID is not a new protected envelope field.

One bounded copy budget includes the attributes root and provider event_id: at most 1024 nodes and depth 8. Nested copying stops at the first excess child and carries truncation into Core's merged event. After the ordinary value budget is exhausted, the root scan continues only to recognize {OriginalFormat}; other keys/values are skipped without validation or copying. Replaced duplicate values count toward copy work; root state enumeration also has a 1024-entry guard so repeated metadata/ignored keys cannot cause an unbounded secondary copy. Unvisited tails, including templates beyond that prefix, are omitted with truncation. Collections remain cooperative caller code; this does not impose an execution deadline on arbitrary enumerator callbacks. Cycles observed in the retained traversal are invalid. No caller map/array remains mutable in queued facts; already immutable LogValue subtrees can be shared.

Nine cases exercise actual Microsoft extension formatting, every supported scalar family, copied nested collections, duplicate/event/scope precedence, unsupported/cyclic input, node/depth/traversal bounds, skipped formatter/state traversal, Activity mutation during enumeration and template clipping. Physical variants use public runtime creation, real JSONL bytes and an exclusive lease probe after stop. The physical borrowedConsoleOpen field is null because that variant does not select a console. Executed reports and independent native-reader controls belong in the task receipt.
