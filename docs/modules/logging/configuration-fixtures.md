The table describes parsed selection before option ranges, identity/path validation or public startup. Formats, stream and detail use portable tokens; severity uses canonical names, numeric settings retain integer domains, and setup uses flattened catalog property paths. Expected snapshots were declared from the documented contract, without running Core to generate their expected values. The existing 350 per-key and nine cross-option vectors remain intact for complete validation qualification in WP03-S03.

[Table tests](../../../implementations/csharp/tests/CIS.Core.UnitTests/ConfigurationTableTests.cs) execute all 26 rows and a completeness/acceptance coverage check, preserving caller inputs and verifying the 21 exact recognized reads once.

The fixture caller copies a supplied host environment label into setup only when EnvironmentName is unspecified. Core receives a string and has no reference to a mutable framework environment object. This demonstrates preservation of supplied labels and the process variable; it is not an ASP.NET hosted-application integration or a new Core framework/environment lookup.

Four rows vary controlled terminal/debugger context. Those context fields are not injected into Core.
