# Logging documentation

Shared concepts and reference material belong here. Language-specific instructions live under `guides/<language>/` once the corresponding implementation can be run.

The source plan's eight examples teach initialization, useful events, JSONL diagnostics, file collection, independent output levels, asynchronous scopes, failure/shutdown and historical consumers. Preserve those teaching objectives when adding runnable documentation.

The current [C# example](../../implementations/csharp/examples/logging/ConsoleHuman/README.md) is a buildable host scaffold. It does not exercise a completed logging runtime.
