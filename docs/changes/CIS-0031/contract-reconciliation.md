## Shared decisions for R01

- Freeze the portable wire version, exact decimal grammar and representability, valid Unicode behavior, typed/opaque input and metadata representation, declarative constraints, stable status/error codes and compatible response rules. Confirm whether and when rule-managed roots can use the existing local restart policy. Choose actual sizes with encoded boundary and one-over cases before dependents commit to wire DTOs.
- Confirm the native deployment-history and exact-version availability model. Pick the same-authority pin/snapshot and release rules that protect queued and retained executions. Prove historical eligibility separately from publication, request generation and instance adoption.
- Choose the RM11 receiver/retention schema and authority on the existing Management provider. Demonstrate out-of-order delivery and existing authorization/producer controls. Define the counter acceptance point, exact dedupe horizon and bulk-reset semantics before projecting hits.
- Confirm the additive discovery shape against RM10's evolving capability discovery work. Keep RM11 behavior independent of Scheduler execution or recurrence. Coordinate shared Management schema/API files when implementation is allocated.

The proposed design uses one accepted local snapshot, the existing Management service and provider, and the existing Audit/Messaging delivery path. Application invocation APIs remain mockable and free of the central service's persistence types.
