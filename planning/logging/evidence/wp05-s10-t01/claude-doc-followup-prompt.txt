## Actual T01 implementation

CoreLogRuntime publishes one shared stop task. Under its existing admission gate, the first caller captures original accepted targets, rejection snapshots and initial invalid/truncated counts; registers the final nondroppable flush controls before idle workers can exit; closes runtime admission; and completes the output queues. Later uncancelled callers receive the same task, without new boundaries, clocks, timers or drain windows.

The runtime validates and copies ShutdownTimeoutMilliseconds before acquiring outputs. Its default is 5000 ms, inclusive range 1 through 300000. Tests mutate caller options before the first stop and again afterwards; the original budget remains fixed. A fresh-process environment case supplies CORE_LOG_SHUTDOWN_TIMEOUT_MS=250 through actual EnvironmentOptions initialization. No new configuration container or resolver is added.

The first caller samples the trusted monotonic clock outside admission synchronization. Preliminary concurrent samples are possible, but only the winning caller starts an operation and one deadline. Existing FlushDeadline consumes elapsed capture/setup time and supplies the fixed expiry observation. UTC labels do not control elapsed time. The shared asynchronous operation starts directly with ExecutionContext flow suppressed, without an extra ThreadPool startup window. No caller factory, payload traversal, clock callback or custom timer disposal runs beneath the admission gate.

The operation awaits actual registered writer flushes, covered-record dispositions and the existing shared worker completion. Normal writer faults become safe failed output results. Its sealed getter-only LogStopResult owns the same fixed-boundary calculation as LogFlushResult; LastStopResult is null until publication and retains that original result afterwards. A deadline can report unresolved work as Pending. Later I/O and live diagnostics cannot change the cached observation.

Complete those assignments before starting consumers; concurrent mutation is not an atomic setup transaction.

Actual internal Core runtime composition owns independent bounded workers, file handles/inventory and its periodic timer. Borrowed console resources stay open. ===== implementations/csharp/src/CIS.Core/Logging/LogStopResult.cs =====
namespace CIS.Logging;

/// <summary>The original owned immutable observation of one shared bounded stop operation.</summary>
/// <remarks>Later live diagnostics may show pending I/O completing; this result does not change or claim disk durability.</remarks>
public sealed class LogStopResult
{
    internal LogStopResult(LogFlushResult observation)
    {
        Completion = observation.Completion; Succeeded = observation.Succeeded; LossObserved = observation.LossObserved;
        BoundaryCapturedAtUtc = observation.BoundaryCapturedAtUtc; ObservedAtUtc = observation.ObservedAtUtc;
        InvalidEventCount = observation.InvalidEventCount; TruncatedEventCount = observation.TruncatedEventCount;
        Outputs = Array.AsReadOnly(observation.Outputs.ToArray());
    }
    /// <summary>Whether covered record dispositions and writer flushes settled; resource cleanup may still be pending.</summary>
    public LogCompletion Completion { get; }
    /// <summary>Whether all covered records were written and writer flushes succeeded.</summary>
    public bool Succeeded { get; }
    /// <summary>Whether initial capture/rejection facts or covered failures confirm loss.</summary>
    public bool LossObserved { get; }
    /// <summary>The system UTC label of original boundary capture, not an elapsed deadline.</summary>
    public DateTimeOffset BoundaryCapturedAtUtc { get; }
    /// <summary>The system UTC label of the cached final observation.</summary>
    public DateTimeOffset ObservedAtUtc { get; }
    /// <summary>The runtime invalid-event count frozen with the original boundary.</summary>
    public long InvalidEventCount { get; }
    /// <summary>The runtime truncation count frozen with the original boundary.</summary>
    public long TruncatedEventCount { get; }
    /// <summary>Owned console-then-file fixed-boundary observations; disabled outputs are omitted.</summary>
    public IReadOnlyList<LogOutputDrainResult> Outputs { get; }
}
