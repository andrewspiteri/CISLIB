Description:
  Retrieve tests connected to an exact graph target by explicit verification evidence.

Usage:
  cis context tests-for [options]

Options:
  --id <id> (REQUIRED)  Required full graph key or exact node-local ID.
  --repo <repo>         Repository path. Defaults to the current directory. [default: C:\miscwork\portfolio\cislib]
  --limit <limit>       Maximum nodes including the target, from 1 to 1000. [default: 100]
  --include-proposed    Include proposed relationships. Rejected relationships remain excluded.
  --format <format>     Output format: human, json, or agent. [default: human]
  -?, -h, --help        Show help and usage information
