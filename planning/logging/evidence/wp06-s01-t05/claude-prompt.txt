def same(actual,expected):
    if type(actual) is not type(expected):return False
    if isinstance(expected,dict):return actual.keys()==expected.keys() and all(same(actual[k],v) for k,v in expected.items())
    if isinstance(expected,list):return len(actual)==len(expected) and all(same(a,b) for a,b in zip(actual,expected))
    return actual==expected

# Microsoft bridge story qualification

WP06-S01 maps the provider category logger into actual Core capture and admission. The [acceptance map](../../../conformance/logging/provider-story-acceptance.json) preserves all five original criterion descriptions and names their executed case bindings. AC05 follows the user-selected single CIS.Core assembly and allowed Microsoft package boundary. AC04 follows the user's truncation requirement for oversized valid payload; unsupported retained payload still invalidates the whole event before admission. Original supplied files remain unchanged.

| Criterion | Qualification |
| --- | --- |
| AC01 | Provider/direct pairs compare six levels and supplied message/exception, plus one structured pair with decimal, UTC timestamp, exact Single widening, Guid, integer-string, nested values, OriginalFormat and actual Activity correlation. Literal typed expectations and automatic identity checks guard both records before equivalence comparison. Caller arrays/maps are mutated only after synchronous capture. |
| AC02 | Named, null and empty names; zero, negative and Int32 boundary numeric IDs; exact categories and log.message fallback. |
| AC03 | Actual Microsoft extension state/rendering; accepted template-last metadata under bounded scans; filtered/None/closed/disposed/all-faulted calls skip callbacks. A full queue remains interested; one faulted output does not prevent healthy output admission. |
| AC04 | Unsupported/cyclic/malformed inputs count invalid once and admit nothing; valid node/depth/template truncation retains bounded output with provenance. Formatter exceptions escape the direct provider logger unchanged without capture accounting. |
| AC05 | Shipping provider is concrete in CIS.Core/CIS.Logging.MicrosoftLogger. Compiled public reflection checks the remaining CIS.Logging surface for Microsoft type leakage. Evaluated projects, restored package closure, compiled assembly references and packaged dependencies follow the existing allowlist with negative controls. |

The unit and fresh-process test families share the concrete fixtures; their assertions are backed by independent native Python readers. A new structured mode closes the combined direct-Core equivalence gap without adding a shipping type. Native readers compare JSON types recursively, including bool/int and int/float distinctions. Only separately captured timestamps are excluded from pair equivalence, after each timestamp passes exact UTC shape and calendar validation. Private data in supplied Exception.Data is excluded in both paths. Corruption controls remove or change representative fields and must fail for the intended reason.

No-output, saturation and writer-fault cases use actual internal queues with controlled callbacks and memory bytes. Other native cases use public runtime creation and real JSONL files. This does not claim operating-system failure injection or a LoggerFactory/host-composed exception contract. Native consumers require exact .NET 10.0.12 with roll-forward disabled and the retained assembly identities. Current execution counts, source checks and reviews belong in the task receipt, not this definition.

The story ends at direct provider/category mapping. WP06-S02 still implements host/external scopes, final provider surface, ILogger<T>/factory integration and host lifecycle. Runnable examples, instructions/skills and full release/compatibility qualification remain pending. This is unpublished implementation qualification; it does not activate a skill, approve a product record or declare a release ready.

using Microsoft.Extensions.Logging;

namespace CIS.Logging.MicrosoftLogger;

/// <summary>Creates Microsoft category loggers that borrow an application-owned core runtime.</summary>
/// <remarks>Disposal disables this provider's future calls and never stops or disposes the shared runtime.
/// A call already running when disposal occurs may finish. Category names follow the core component rules.
/// Supplied rendered messages and exceptions enter core capture. Null or empty EventId.Name becomes
/// log.message; EventId.Id supplies the integer attribute event_id, including zero and negative values.
/// Structured state preserves {OriginalFormat} without parsing. Core checks interest before invoking
/// formatter or copying state; full queues remain interested. Formatter exceptions propagate unchanged;
/// invalid retained payload increments core diagnostics without output admission. Oversized valid payload
/// is truncated. Disposed, stopped, filtered and all-faulted calls skip both callbacks after argument guards.
/// Healthy outputs admit independently; host scopes remain integration work.</remarks>
public sealed class CoreLoggerProvider : ILoggerProvider
{
    private readonly CoreLogRuntime runtime;
    private int disposed;

    /// <summary>Creates a nonowning provider over an existing runtime.</summary>
    /// <exception cref="ArgumentNullException">Runtime is null.</exception>
    public CoreLoggerProvider(CoreLogRuntime runtime)
    {
        ArgumentNullException.ThrowIfNull(runtime);
        this.runtime = runtime;
    }

    /// <summary>Creates a category logger using the core's validated component name.</summary>
    /// <exception cref="ObjectDisposedException">This provider has been disposed.</exception>
    /// <exception cref="ArgumentNullException">Category name is null.</exception>
    /// <exception cref="ArgumentException">The name does not satisfy the core component rules.</exception>
    public ILogger CreateLogger(string categoryName)
    {
        ObjectDisposedException.ThrowIf(IsDisposed, this);
        return new CategoryLogger(this, runtime.CreateLogger(categoryName));
    }

    private bool IsDisposed => Volatile.Read(ref disposed) != 0;

    /// <summary>Idempotently disables this provider; the application retains runtime ownership.</summary>
    public void Dispose() => Interlocked.Exchange(ref disposed, 1);

    private static CoreLogLevel Level(LogLevel logLevel)
    {
        if (!Enum.IsDefined(logLevel)) { throw new ArgumentOutOfRangeException(nameof(logLevel)); }
        // The selected v1 Core and Microsoft severity numbers are identical (Trace through None).
        return (CoreLogLevel)logLevel;
    }

    private sealed class CategoryLogger(CoreLoggerProvider provider, CoreLogger core) : ILogger
    {
        public bool IsEnabled(LogLevel logLevel)
        {
            CoreLogLevel level = Level(logLevel);
            return !provider.IsDisposed && core.IsEnabled(level);
        }

        public IDisposable? BeginScope<TState>(TState state) where TState : notnull
        {
            ArgumentNullException.ThrowIfNull(state);
            ObjectDisposedException.ThrowIf(provider.IsDisposed, provider);
            if (state is not OperationContextData context)
            { throw new ArgumentException("Use OperationContextData for the provider foundation's typed core scope.", nameof(state)); }
            if (provider.runtime.GetDiagnostics().AdmissionClosed) { throw new InvalidOperationException("Cannot begin a scope after runtime admission closes."); }
            return provider.runtime.Scopes.BeginScope(context);
        }

        public void Log<TState>(LogLevel logLevel, EventId eventId, TState state, Exception? exception,
            Func<TState, Exception?, string> formatter)
        {
            ArgumentNullException.ThrowIfNull(formatter);
            CoreLogLevel level = Level(logLevel);
            if (provider.IsDisposed) { return; }
            _ = core.WriteLazy(level, () => new LogEventData
            {
                EventName = string.IsNullOrEmpty(eventId.Name) ? "log.message" : eventId.Name,
                Message = formatter(state, exception),
                Exception = exception,
                CaptureState = () => ProviderStateCapture.Capture(state, eventId.Id)
            });
        }
    }
}

using System.Collections;
using System.Globalization;
using CIS.Logging.Values;

namespace CIS.Logging.MicrosoftLogger;

// A single bounded synchronous copy; no template parsing or arbitrary object serialization.
internal sealed class ProviderStateCapture
{
    private int remaining = LogValueProjection.MaximumNodes - 2; // Root plus provider-owned event_id.
    private readonly HashSet<object> ancestors = new(ReferenceEqualityComparer.Instance);

    internal static (string? Template, LogValue Attributes) Capture<TState>(TState state, int eventId)
    {
        var capture = new ProviderStateCapture();
        var attributes = new Dictionary<string, LogValue>(StringComparer.Ordinal) { ["event_id"] = LogValue.Integer(eventId) };
        if (state is not IEnumerable<KeyValuePair<string, object?>> fields)
        { return (null, LogValue.OwnedMap(attributes, truncated: false)); }
        string? template = null; bool truncated = false; int visited = 0;
        capture.Enter(fields);
        try
        {
            foreach ((string key, object? value) in fields)
            {
                if (++visited > LogValueProjection.MaximumNodes) { truncated = true; break; }
                if (key == "{OriginalFormat}")
                {
                    if (value is not null and not string) { throw new ArgumentException("OriginalFormat must be a string or null."); }
                    template = (string?)value; continue;
                }
                if (key == "event_id") { continue; }
                // Keep scanning bounded root metadata after the value budget is spent.
                if (capture.remaining == 0) { truncated = true; continue; }
                ValidateKey(key);
                LogValue? retained = capture.Value(value, depth: 2);
                if (retained is null) { truncated = true; continue; }
                attributes[key] = retained;
            }
        }
        finally { capture.ancestors.Remove(fields); }
        return (template, LogValue.OwnedMap(attributes, truncated));
    }

    private LogValue? Value(object? value, int depth)
    {
        if (remaining == 0 || depth > LogValueProjection.MaximumDepth) { return null; }
        if (value is LogValue existing && existing.NodeCount <= remaining && depth - 1 + existing.Depth <= LogValueProjection.MaximumDepth)
        { remaining -= existing.NodeCount; return existing; }
        remaining--;
        return value switch
        {
            null => LogValue.Null(),
            LogValue owned when owned.Kind == LogValueKind.Array => Array(owned.ArrayItems, depth, owned.IsTruncated),
            LogValue owned when owned.Kind == LogValueKind.Map => Map(owned.MapProperties.Select(p => new KeyValuePair<string, object?>(p.Key, p.Value)), depth, owned.IsTruncated),
            bool scalar => LogValue.Boolean(scalar),
            string scalar => LogValue.String(scalar),
            char scalar => LogValue.String(new string(scalar, 1)),
            sbyte scalar => LogValue.Integer(scalar),
            byte scalar => LogValue.Integer(scalar),
            short scalar => LogValue.Integer(scalar),
            ushort scalar => LogValue.Integer(scalar),
            int scalar => LogValue.Integer(scalar),
            uint scalar => LogValue.Integer(scalar),
            long scalar => LogValue.Integer(scalar),
            ulong scalar when scalar <= 9_007_199_254_740_991 => LogValue.Integer((long)scalar),
            float scalar => LogValue.Number(scalar),
            double scalar => LogValue.Number(scalar),
            decimal scalar => Decimal(scalar),
            Guid scalar => LogValue.Uuid(scalar),
            DateTimeOffset scalar => LogValue.Timestamp(scalar),
            DateTime scalar when scalar.Kind == DateTimeKind.Utc => LogValue.Timestamp(new DateTimeOffset(scalar)),
            IEnumerable<KeyValuePair<string, object?>> properties => Map(properties, depth),
            IDictionary properties => Map(Entries(properties), depth, owner: properties),
            IEnumerable items => Array(items, depth),
            _ => throw new ArgumentException("Use supported scalar, collection or explicit LogValue inputs.")
        };
    }

    private LogValue Array(IEnumerable items, int depth, bool truncated = false)
    {
        Enter(items);
        try
        {
            var owned = new List<LogValue>();
            foreach (object? item in items)
            {
                LogValue? retained = Value(item, depth + 1);
                if (retained is null) { truncated = true; break; }
                owned.Add(retained);
            }
            return LogValue.OwnedArray(owned, truncated);
        }
        finally { ancestors.Remove(items); }
    }

    private LogValue Map(IEnumerable<KeyValuePair<string, object?>> properties, int depth, bool truncated = false, object? owner = null)
    {
        owner ??= properties; Enter(owner);
        try
        {
            var owned = new Dictionary<string, LogValue>(StringComparer.Ordinal);
            foreach ((string key, object? value) in properties)
            {
                ValidateKey(key);
                LogValue? retained = Value(value, depth + 1);
                if (retained is null) { truncated = true; break; }
                owned[key] = retained;
            }
            return LogValue.OwnedMap(owned, truncated);
        }
        finally { ancestors.Remove(owner); }
    }

    private static IEnumerable<KeyValuePair<string, object?>> Entries(IDictionary properties)
    {
        foreach (DictionaryEntry entry in properties)
        { yield return new(entry.Key as string ?? throw new ArgumentException("Map keys must be strings."), entry.Value); }
    }

    private void Enter(object collection)
    {
        if (!ancestors.Add(collection)) { throw new ArgumentException("Cyclic state is unsupported."); }
    }
    private static void ValidateKey(string key)
    {
        if (key is null || !LogValueText.IsValidKey(key)) { throw new ArgumentException("Use valid ordinal attribute keys."); }
    }
    private static LogValue Decimal(decimal value)
    {
        string text = value.ToString(CultureInfo.InvariantCulture);
        return LogValue.DecimalString(text.Contains('.', StringComparison.Ordinal) ? text : text + ".0");
    }
}

    /// <summary>Starts or joins one shared bounded stop operation through its original accepted boundaries.</summary>
    /// <param name="cancellationToken">Cancels only this caller's wait; even an already-cancelled first caller starts shutdown.</param>
    /// <returns>The same owned immutable observation retained for all joining callers.</returns>
    /// <exception cref="OperationCanceledException">The caller cancels its own wait.</exception>
    /// <remarks>The configured overall timeout is frozen at creation. UTC is an observation label; elapsed time is monotonic. At expiry, unstarted accepted records are abandoned. Cancellation of active writes/flushes is requested but is not guaranteed, and no new flush, retry or replacement writer starts. Completed means terminal dispositions, not successful delivery or resource release. A timed-out observation can retain pending I/O; its later completion does not change the cached result.</remarks>
    public Task<LogStopResult> StopAsync(CancellationToken cancellationToken)
    {
        if (queuedOutputs is null) { throw new InvalidOperationException("Stop requires actual queued output composition."); }
        Task<LogStopResult>? shared;
        lock (admissionGate) { shared = stopTask; }
        if (shared is null)
        {
            // Caller clock code is never invoked under admission synchronization.
            // Preliminary concurrent samples are harmless; only the winning caller owns the deadline.
            long started = timeProvider.GetTimestamp();
            RuntimeFlushBoundary boundary = default;
            TaskCompletionSource<LogStopResult>? completion = null;
            lock (admissionGate)
            {
                if (stopTask is null)
                {
                    completion = new(TaskCreationOptions.RunContinuationsAsynchronously);
                    stopTask = completion.Task;
                    try
                    {
                        // Register final controls before a closing idle worker is allowed to exit.
                        boundary = RegisterFlushBoundary();
                        shutdownStartedAtUtc ??= boundary.BoundaryCapturedAtUtc;
                        admissionClosed = true;
                        queuedOutputs.Complete();
                    }
                    catch (Exception error)
                    {
                        // A failed setup must not leave the already-published task pending forever.
                        completion.TrySetException(error);
                        throw;
                    }
                }
                shared = stopTask;
            }
            if (completion is not null)
            {
                // Start deadline acquisition directly, without a delayed ThreadPool launch.
                // Only continuations/timers outlive this call; they do not retain the caller's flow.
                if (ExecutionContext.IsFlowSuppressed()) { _ = RunStopAsync(boundary, started, completion); }
                else { using (ExecutionContext.SuppressFlow()) { _ = RunStopAsync(boundary, started, completion); } }
            }
        }
        // WaitAsync can prefer an already-completed task; an already-cancelled caller must still cancel.
        if (cancellationToken.IsCancellationRequested) { return Task.FromCanceled<LogStopResult>(cancellationToken); }
        return cancellationToken.CanBeCanceled ? shared!.WaitAsync(cancellationToken) : shared!;
    }

    /// <summary>Starts or joins the original bounded stop operation without a new drain window.</summary>
    /// <returns>A wait on the same shared operation; unsuccessful draining remains visible in LastStopResult.</returns>
    /// <remarks>Repeated disposal is harmless. At the original deadline this wait may complete while actual I/O and owned cleanup remain pending; no resource is disposed beneath active I/O. Inspect GetDiagnostics().LastStopResult for the immutable drain outcome.</remarks>
    public ValueTask DisposeAsync() => new(StopAsync(CancellationToken.None));

    private async Task RunStopAsync(RuntimeFlushBoundary boundary, long started, TaskCompletionSource<LogStopResult> completion)
    {
        try
        {
            if (boundary.Console is null && boundary.File is null)
            { PublishStop(CaptureFlushResult(boundary), completion); return; }
            await using var deadline = new FlushDeadline(timeProvider, started, shutdownTimeout, () => CaptureFlushResult(boundary), () => CaptureStopDeadline(boundary));
            try
            {
                await boundary.WaitForWriterFlushAsync(deadline.Token).ConfigureAwait(false);
                if (boundary.Console is { } console)
                { await queuedOutputs!.Console!.WaitForCoveredRecordsAsync("console", console, deadline.Token).ConfigureAwait(false); }
                if (boundary.File is { } file)
                { await queuedOutputs!.File!.WaitForCoveredRecordsAsync("file", file, deadline.Token).ConfigureAwait(false); }
                try { await queuedOutputs!.Completion.WaitAsync(deadline.Token).ConfigureAwait(false); }
                catch (Exception) when ((queuedOutputs!.Completion.IsFaulted || queuedOutputs.Completion.IsCanceled) && (queuedOutputs.Console?.IsFaulted == true || queuedOutputs.File?.IsFaulted == true))
                { /* Terminal writer faults remain safe output results, not business-call I/O exceptions. */ }
            }
            catch (OperationCanceledException) when (deadline.Token.IsCancellationRequested) { }
            // Publish the frozen result before asynchronous deadline-timer cleanup can wait on a callback join.
            PublishStop(deadline.ObserveCompletion(), completion);
        }
        catch (Exception error)
        {
            if (completion.Task.IsCompletedSuccessfully)
            {
                // Publication precedes deadline-timer cleanup; later failure belongs to live diagnostics.
                queuedOutputs!.RecordCleanupFault("ShutdownTimerCleanupFailed");
            }
            else { completion.TrySetException(error); }
        }
    }

    private LogFlushResult CaptureStopDeadline(RuntimeFlushBoundary boundary)
    {
        LogFlushResult observation;
        lock (admissionGate)
        {
            queuedOutputs!.AbandonUnstarted();
            observation = CaptureFlushResult(boundary);
        }
        // Freeze actual pending work before cooperative cancellation can settle it.
        queuedOutputs.RequestIoCancellation();
        return observation;
    }
    private void PublishStop(LogFlushResult observation, TaskCompletionSource<LogStopResult> completion)
    {
        var result = new LogStopResult(observation);
        lock (admissionGate) { lastStopResult = result; }
        completion.TrySetResult(result);
    }


    /// <summary>Waits through fixed accepted boundaries and confirms each enabled writer's buffer flush.</summary>
    /// <param name="timeout">One positive finite overall wait budget; every positive TimeSpan is supported.</param>
    /// <param name="cancellationToken">Cancels only this caller's wait, preserving shared worker requests.</param>
    /// <returns>An owned immutable observation, including unresolved work at the deadline.</returns>
    /// <exception cref="ArgumentOutOfRangeException">The timeout is zero, negative or infinite.</exception>
    /// <exception cref="OperationCanceledException">The caller token is cancelled, including after boundary registration.</exception>
    /// <remarks>UTC labels are system observations; elapsed deadlines use the runtime TimeProvider. Flush does not stop admission or guarantee disk durability. After closure it cannot reopen a writer; a terminal writer returns an unavailable/failed flush even if the original stop flushed successfully. Inspect LastStopResult for that original shutdown outcome.</remarks>
    public Task<LogFlushResult> FlushAsync(TimeSpan timeout, CancellationToken cancellationToken)
    {
        if (timeout.Ticks <= 0) { throw new ArgumentOutOfRangeException(nameof(timeout)); }
        long started = timeProvider.GetTimestamp();
        RuntimeFlushBoundary boundary = RegisterFlushBoundary();
        return ObserveFlushAsync(boundary, started, timeout, cancellationToken);
    }
    private async Task<LogFlushResult> ObserveFlushAsync(RuntimeFlushBoundary boundary, long started, TimeSpan timeout, CancellationToken caller)
    {
        caller.ThrowIfCancellationRequested();
        if (boundary.Console is null && boundary.File is null) { return CaptureFlushResult(boundary); }
        await using var deadline = new FlushDeadline(timeProvider, started, timeout, () => CaptureFlushResult(boundary));
        using var wait = CancellationTokenSource.CreateLinkedTokenSource(caller, deadline.Token);
        try
        {
            await boundary.WaitForWriterFlushAsync(wait.Token).ConfigureAwait(false);
            // A terminal unavailable flush can precede the disposition of an already-started write.
            if (boundary.Console is { } console)
            { await queuedOutputs!.Console!.WaitForCoveredRecordsAsync("console", console, wait.Token).ConfigureAwait(false); }
            if (boundary.File is { } file)
            { await queuedOutputs!.File!.WaitForCoveredRecordsAsync("file", file, wait.Token).ConfigureAwait(false); }
        }
        catch (OperationCanceledException) when (wait.IsCancellationRequested)
        { caller.ThrowIfCancellationRequested(); }
        caller.ThrowIfCancellationRequested();
        return deadline.ObserveCompletion();
    }
    private LogFlushResult CaptureFlushResult(RuntimeFlushBoundary boundary)
    {
        lock (admissionGate)
        {
            var observations = new List<LogOutputDrainResult>(2);
            if (boundary.Console is { } console) { observations.Add(queuedOutputs!.Console!.CaptureDrain("console", console)); }
            if (boundary.File is { } file) { observations.Add(queuedOutputs!.File!.CaptureDrain("file", file)); }
            return new LogFlushResult(boundary.BoundaryCapturedAtUtc, DateTimeOffset.UtcNow,
                boundary.InvalidEventCount, boundary.TruncatedEventCount, observations);
        }
    }
    internal RuntimeFlushBoundary RegisterFlushBoundary()
    {
        if (queuedOutputs is null) { throw new InvalidOperationException("Flush boundaries require actual queued output composition."); }
        lock (admissionGate)
        {
            // Pure system UTC sampling here does not invoke caller factories, payloads or the event clock.
            DateTimeOffset capturedAt = DateTimeOffset.UtcNow;
            OutputFlushBoundary? console = queuedOutputs.Console?.RegisterFlushBoundary();
            OutputFlushBoundary? file = queuedOutputs.File?.RegisterFlushBoundary();
            return new RuntimeFlushBoundary(capturedAt, InvalidEventCount, TruncatedEventCount, console, file);
        }
    }
    internal RuntimeAccounting CaptureAccounting()
    {
        if (queuedOutputs is null) { throw new InvalidOperationException("Accounting requires actual queued output composition."); }
        lock (admissionGate)
        {
            // Output/disposition/truncation/closure changes share this gate. Invalid increments
            // independently, so its atomic read chooses the observation point while the rest is stable.
            return new RuntimeAccounting(admissionClosed, InvalidEventCount, TruncatedEventCount,
                queuedOutputs.Console?.CaptureAccounting(), queuedOutputs.File?.CaptureAccounting());
        }
    }

    /// <summary>Returns an owned immutable live observation without routing a log or performing output I/O.</summary>
    /// <remarks>Available after faults and admission closure. This does not register a fixed flush target.</remarks>
    public CoreLogDiagnostics GetDiagnostics()
    {
        lock (admissionGate)
        {
            RuntimeAccounting counts = CaptureAccounting();
            var values = new List<LogOutputDiagnostics>(2);
            if (counts.Console is OutputAccounting console) { values.Add(new LogOutputDiagnostics("console", console)); }
            if (counts.File is OutputAccounting file) { values.Add(new LogOutputDiagnostics("file", file, recoveredPartialSegment)); }
            CoreLogState state = !counts.AdmissionClosed ? CoreLogState.Running :
                values.All(value => value.State == LogOutputState.Stopped) ? CoreLogState.Stopped : CoreLogState.Stopping;
            return new CoreLogDiagnostics(state, counts.AdmissionClosed, DateTimeOffset.UtcNow, shutdownStartedAtUtc,
                counts.InvalidEventCount, counts.TruncatedEventCount, values, lastStopResult);
        }
    }

    internal LogWriteResult Write(string component, CoreLogLevel level, LogEventData? data, Func<LogEventData>? factory)
    {
        ValidateLevel(level);
        bool renderConsole, renderFile;
        lock (admissionGate)
        {
            if (admissionClosed) { return Stopped(isTruncated: false); }
            if (!outputs.Any(output => Interested(output, level))) { return FinishWithoutCapture(level, LogWriteOutcome.Filtered); }
            if (!outputs.Any(output => Interested(output, level) && !output.Admission.IsFaulted))
            {
                return FinishWithoutCapture(level, LogWriteOutcome.Rejected);
            }
            renderConsole = consoleWriter is not null && outputs.Any(output => output.Name == "console" && Interested(output, level) && !output.Admission.IsFaulted);
            renderFile = fileWriter is not null && outputs.Any(output => output.Name == "file" && Interested(output, level) && !output.Admission.IsFaulted);
        }
        // No gate is held around caller factories, clock, scopes or payload callbacks.
        if (factory is not null) { data = factory(); }
        if (data is null) { return Invalid("InvalidFactoryResult"); }
        string? eventName = data.EventName;
        string? message = data.Message;
        string? template = data.MessageTemplate;
        string? operationId = data.OperationId;
        CapturedEventFacts facts;
        try
        {
            facts = EventProjection.Capture(metadata, Scopes.Capture(), component, level, data, timeProvider)!;
        }
        catch (Exception error) when (error is not (OutOfMemoryException or StackOverflowException))
        {
            return Invalid(CaptureError(eventName, message, template, operationId));
        }
        EncodedEvent captured;
        RenderedEvent? preparedConsole = null, preparedFile = null;
        // Other owned encoding/rendering consistency errors are Core defects, not invalid caller content.
        try
        {
            captured = EventEncoder.Encode(facts, maximumEntryBytes);
            if (renderConsole) { preparedConsole = consoleWriter!.Prepare(captured); }
            if (renderFile) { preparedFile = fileWriter!.Prepare(captured); }
        }
        catch (EventEnvelopeTooLargeException) { return Invalid("EnvelopeTooLarge"); }
        bool isTruncated = captured.IsTruncated || preparedConsole?.IsTruncated == true || preparedFile?.IsTruncated == true;
        lock (admissionGate)
        {
            if (isTruncated) { IncrementLossCounter(ref truncatedEventCount); }
            if (admissionClosed) { return Stopped(isTruncated); }
            return Admit(level, captured, preparedConsole?.Line, preparedFile?.Line, isTruncated);
        }
    }

    // Primitive internal qualification closure: no final flush or bounded shutdown is promised.
    // Supported applications use StopAsync/DisposeAsync; a later flush cannot reopen an exited worker.
    internal void CloseAdmission()
    {
        lock (admissionGate) { shutdownStartedAtUtc ??= DateTimeOffset.UtcNow; admissionClosed = true; queuedOutputs?.Complete(); }
    }

    private LogWriteResult Invalid(string code)
    {
        IncrementLossCounter(ref invalidEventCount);
        return new LogWriteResult(LogWriteOutcome.InvalidEvent, [], code);
    }

    // Loss counters retain a nonnegative lower bound once Int64 can no longer represent the total.
    private static void IncrementLossCounter(ref long counter)
    {
        long current = Interlocked.Read(ref counter);
        while (current != long.MaxValue)
        {
            long observed = Interlocked.CompareExchange(ref counter, current + 1, current);
            if (observed == current) { return; }
            current = observed;
        }
    }

    private LogWriteResult Stopped(bool isTruncated) => new(LogWriteOutcome.Stopped,
        outputs.Select(output => new LogOutputWriteResult(output.Name, LogOutputWriteStatus.Stopped, null)), isTruncated: isTruncated);

    private LogWriteResult FinishWithoutCapture(CoreLogLevel level, LogWriteOutcome outcome)
    {
        var observations = new List<LogOutputWriteResult>(outputs.Length);
        foreach (Output output in outputs)
        {
            LogOutputWriteStatus status;
            if (Interested(output, level))
            {
                output.Admission.RecordUnavailable();
                status = LogOutputWriteStatus.Faulted;
            }
            else
            {
                output.Admission.RecordFiltered();
                status = LogOutputWriteStatus.Filtered;
            }
            observations.Add(new LogOutputWriteResult(output.Name, status, null));
        }
        return new LogWriteResult(outcome, observations);
    }

    private LogWriteResult Admit(CoreLogLevel level, EncodedEvent captured, ReadOnlyMemory<byte>? consoleLine, ReadOnlyMemory<byte>? fileLine, bool isTruncated)
    {
        var observations = new List<LogOutputWriteResult>(outputs.Length);
        int accepted = 0;
        int interested = 0;
        foreach (Output output in outputs)
        {
            long? sequence = null;
            LogOutputWriteStatus status;
            if (!Interested(output, level))
            {
                output.Admission.RecordFiltered();
                status = LogOutputWriteStatus.Filtered;
            }
            else
            {
                interested++;
                if (output.Admission.IsFaulted)
                {
                    output.Admission.RecordUnavailable();
                    status = LogOutputWriteStatus.Faulted;
                }
                else if (output.Name == "console" && consoleLine is { } preparedLine)
                { status = queuedOutputs!.Console!.TryAdmit(captured, preparedLine, out sequence); }
                else if (output.Name == "file" && fileLine is { } preparedFileLine)
                { status = queuedOutputs!.File!.TryAdmit(captured, preparedFileLine, out sequence); }
                else { status = output.Admission.TryAdmit(captured, out sequence); }
                if (status == LogOutputWriteStatus.Accepted) { accepted++; }
            }
            if (Interested(output, level) && status is not (LogOutputWriteStatus.Accepted or LogOutputWriteStatus.QueueFull or LogOutputWriteStatus.Faulted))
            {
                throw new InvalidOperationException("Output admission returned an invalid status.");
            }
            if (status == LogOutputWriteStatus.Accepted ? sequence is null or <= 0 : sequence is not null)
            {
                throw new InvalidOperationException("Output admission returned an invalid ticket.");
            }
            observations.Add(new LogOutputWriteResult(output.Name, status, sequence));
        }
        LogWriteOutcome outcome = LogWriteOutcome.Rejected;
        if (accepted == interested) { outcome = LogWriteOutcome.Accepted; }
        else if (accepted > 0) { outcome = LogWriteOutcome.PartiallyAccepted; }
        return new LogWriteResult(outcome, observations, isTruncated: isTruncated);
    }

    private static string CaptureError(string? name, string? message, string? template, string? operationId)
    {
        foreach (string? text in new[] { name, message, template, operationId })
        {
            if (text is not null && !UnicodeScalarText.IsValid(text, int.MaxValue, allowControls: true)) { return "InvalidUnicode"; }
        }
        if (string.IsNullOrEmpty(name) || !UnicodeScalarText.IsValid(name, 255, allowControls: false)) { return "InvalidEventName"; }
        if (message is null) { return "InvalidMessage"; }
        string? operation = operationId?.Trim();
        if (!string.IsNullOrEmpty(operation) && !UnicodeScalarText.IsValid(operation, 255, allowControls: false)) { return "InvalidOperationId"; }
        // Arbitrary cooperative callback/unsupported payload failures expose only this fixed code.
        return "UnsupportedValue";
    }

    private static bool Interested(Output output, CoreLogLevel level) => level != CoreLogLevel.None && level >= output.Threshold;
    private static void ValidateSettings(CoreLogLevel console, CoreLogLevel file, int maximumBytes)
    {
        ValidateLevel(console); ValidateLevel(file);
        if (maximumBytes is < LoggingOptions.MinimumMaxEntryBytes or > LoggingOptions.MaximumMaxEntryBytes) { throw new ArgumentOutOfRangeException("options"); }
    }
    private static void ValidateLevel(CoreLogLevel level)
    {
        if (!Enum.IsDefined(level)) { throw new ArgumentOutOfRangeException(nameof(level), "Use a declared logging level."); }
    }
    private sealed record Output(string Name, CoreLogLevel Threshold, ILogOutputAdmission Admission);
}

namespace CIS.Logging.Events;

internal static class EventProjection

    internal const int MaximumPayloadScalars = 8192;

    internal static CapturedEventFacts? Capture(EventMetadata metadata, CapturedScopeContext scope,
        string component, CoreLogLevel severity, LogEventData data, TimeProvider? timeProvider = null)
    {
        string? status = severity switch
        {
            CoreLogLevel.Trace => "trace",
            CoreLogLevel.Debug => "debug",
            CoreLogLevel.Information => "info",
            CoreLogLevel.Warning => "warn",
            CoreLogLevel.Error => "error",
            CoreLogLevel.Critical => "critical",
            CoreLogLevel.None => null,
            _ => throw new ArgumentOutOfRangeException(nameof(severity), "Use a declared logging severity.")
        };
        if (status is null) { return null; }
        ArgumentNullException.ThrowIfNull(metadata);
        ArgumentNullException.ThrowIfNull(scope);
        ArgumentNullException.ThrowIfNull(data);
        ValidateName(component, nameof(component));

        // Read named input references before invoking cooperative collection/exception accessors.
        string eventName = data.EventName;
        string message = data.Message;
        string? template = data.MessageTemplate;
        string? operationId = data.OperationId?.Trim();
        IReadOnlyDictionary<string, LogValue>? sourceAttributes = data.Attributes;
        Exception? sourceException = data.Exception;
        Func<(string? Template, LogValue Attributes)>? sourceState = data.CaptureState;
        ValidateName(eventName, nameof(data));
        // Own Activity IDs before clock/payload callbacks can replace the ambient context.
        (string? traceId, string? spanId) = CaptureActivity();
        DateTimeOffset timestampUtc = (timeProvider ?? TimeProvider.System).GetUtcNow().ToUniversalTime();
        (string? Template, LogValue Attributes)? adapted = sourceState?.Invoke();
        template = adapted?.Template ?? template;
        string capturedMessage = CaptureText(message, out bool messageClipped);
        bool templateClipped = false;
        string? capturedTemplate = template is null ? null : CaptureText(template, out templateClipped);
        if (string.IsNullOrEmpty(operationId)) { operationId = scope.OperationId; }
        else if (!UnicodeScalarText.IsValid(operationId, 255, allowControls: false))
        {
            throw new ArgumentException("Use an operation identifier of at most 255 valid Unicode scalars without controls.", nameof(data));
        }
        LogValue explicitAttributes = adapted?.Attributes ?? LogValue.Map(sourceAttributes ?? new Dictionary<string, LogValue>());
        LogValue attributes = Merge(scope.Attributes, explicitAttributes);
        CapturedException? exception = ExceptionProjection.Capture(sourceException);
        return new CapturedEventFacts(timestampUtc, traceId, spanId, status, eventName, capturedMessage, capturedTemplate, operationId,
            metadata.ApplicationName, metadata.EnvironmentName, metadata.ServiceVersion, component,
            Resource(metadata), attributes, exception,
            messageClipped || templateClipped || attributes.IsTruncated || exception?.HasTruncatedContent == true);
    }

    private static (string? TraceId, string? SpanId) CaptureActivity()
    {
        Activity? activity = Activity.Current;
        if (activity?.IdFormat != ActivityIdFormat.W3C) { return (null, null); }
        string traceId = activity.TraceId.ToHexString();
        string spanId = activity.SpanId.ToHexString();
        return IsValidHexId(traceId, 32) && IsValidHexId(spanId, 16) ? (traceId, spanId) : (null, null);
    }

    private static bool IsValidHexId(string value, int length)
    {
        if (value.Length != length) { return false; }
        bool nonzero = false;
        foreach (char character in value)
        {
            if (!(character is >= '0' and <= '9' or >= 'a' and <= 'f')) { return false; }
            nonzero |= character != '0';
        }
        return nonzero;
    }

    private static void ValidateName(string value, string parameter)
    {
        ArgumentNullException.ThrowIfNull(value, parameter);
        if (value.Length == 0 || !UnicodeScalarText.IsValid(value, 255, allowControls: false))
        {
            throw new ArgumentException("Use a name of 1-255 valid Unicode scalars without controls.", parameter);
        }
    }

    private static string CaptureText(string value, out bool truncated)
    {
        ArgumentNullException.ThrowIfNull(value, "data");
        // Unlike bounded exception accessors, the named message/template is a supplied string.
        // Malformed input remains invalid even in the suffix that the scalar limit would omit.
        if (!LogValueText.IsValidUnicode(value))
        {
            throw new ArgumentException("Use valid Unicode scalar text.", "data");
        }
        return UnicodeScalarText.Prefix(value, MaximumPayloadScalars, out truncated);
    }

    private static LogValue Merge(LogValue scope, LogValue explicitAttributes)
    {
        var winners = new Dictionary<string, LogValue>(StringComparer.Ordinal);
        bool truncated = scope.IsTruncated || explicitAttributes.IsTruncated;
        foreach (LogValue map in new[] { scope, explicitAttributes })
        {
            foreach ((string key, LogValue value) in map.MapProperties)
            {
                if (winners.ContainsKey(key) || winners.Count < LogValueProjection.MaximumNodes - 1) { winners[key] = value; }
                else { truncated = true; }
            }
        }
        return new LogValueProjection().Map(winners, depth: 1, truncated);
    }

    private static LogValue Resource(EventMetadata metadata)
    {
        var resource = new Dictionary<string, LogValue>(StringComparer.Ordinal)
        {
            ["build_version"] = LogValue.String(metadata.BuildVersion),
            ["instance_id"] = LogValue.String(metadata.InstanceId),
            ["initialized_at"] = LogValue.Timestamp(metadata.InitializedAtUtc),
            ["environment_kind"] = LogValue.String(metadata.EnvironmentKind switch
            {
                EnvironmentKind.Unknown => "unknown",
                EnvironmentKind.Console => "console",
                EnvironmentKind.Service => "service",
                EnvironmentKind.Web => "web",
                EnvironmentKind.Function => "function",
                _ => throw new InvalidOperationException("Invalid owned environment kind.")
            }),
            ["os_family"] = LogValue.String(metadata.OperatingSystem)
        };
        if (metadata.ProcessStartedAtUtc is { } started) { resource["process_started_at"] = LogValue.Timestamp(started); }
        Add("host_name", metadata.HostName);
        Add("os_description", metadata.OperatingSystemDescription);
        Add("os_architecture", metadata.OSArchitecture);
        Add("process_architecture", metadata.ProcessArchitecture);
        Add("runtime_description", metadata.RuntimeDescription);
        if (metadata.ProcessId is { } processId) { resource["process_id"] = LogValue.Integer(processId); }
        Add("commit_id", metadata.CommitId);
        Add("build_id", metadata.BuildId);
        return LogValue.Map(resource);

        void Add(string key, string? value) { if (value is not null) { resource[key] = LogValue.String(value); } }
    }
}

/// <summary>An immutable, explicitly typed scalar or owned collection of attribute values.</summary>
/// <remarks>Collection inputs are copied; already immutable child values may be shared.
/// Every collection root is node 1 at depth 1; retained shapes have at most 1024 nodes and depth 8.
/// Oversized collections keep a bounded projection and carry truncation provenance.
/// UUID/time factories accept typed scalars; arbitrary objects have no conversion path.
/// Event capture/rendering applies the separately configured aggregate entry limit.</remarks>
public sealed class LogValue
{
    private const long MaximumSafeInteger = 9_007_199_254_740_991;
    private readonly LogValueScalar scalar;
    private readonly ReadOnlyCollection<LogValue>? array;
    private readonly ReadOnlyDictionary<string, LogValue>? map;

    private LogValue(LogValueKind kind, LogValueScalar scalar = default,
        ReadOnlyCollection<LogValue>? array = null, ReadOnlyDictionary<string, LogValue>? map = null, bool isTruncated = false)
    {
        Kind = kind;
        this.scalar = scalar;
        this.array = array;
        this.map = map;
        var shape = (Nodes: 1, Depth: 1, Truncated: false);
        if (array is not null)
        {
            shape = Measure(array);
        }
        else if (map is not null)
        {
            shape = Measure(map.Values);
        }
        NodeCount = shape.Nodes;
        Depth = shape.Depth;
        IsTruncated = isTruncated || shape.Truncated;
    }

    /// <summary>Gets the constructor-selected representation; magnitude never changes it.</summary>
    public LogValueKind Kind { get; }

    /// <summary>Gets whether this value or a retained descendant has omitted content.</summary>
    /// <remarks>Collection projection propagates prior and newly observed truncation.
    /// Aggregate entry-byte projection remains an event capture/rendering responsibility.</remarks>
    public bool IsTruncated { get; }

    internal int NodeCount { get; }
    internal int Depth { get; }
    internal LogValueScalar Scalar => scalar;
    internal IReadOnlyList<LogValue> ArrayItems => array ?? throw new InvalidOperationException("Value is not an array.");
    internal IReadOnlyDictionary<string, LogValue> MapProperties => map ?? throw new InvalidOperationException("Value is not a map.");

    /// <summary>Creates an explicit null value.</summary>
    public static LogValue Null() => new(LogValueKind.Null);

    /// <summary>Creates a Boolean value.</summary>
    public static LogValue Boolean(bool value) => new(LogValueKind.Boolean, new(value));

    /// <summary>Creates a string, preserving valid Unicode text and control characters.</summary>
    /// <exception cref="ArgumentNullException">value is null.</exception>
    /// <exception cref="ArgumentException">value contains malformed UTF-16.</exception>
    public static LogValue String(string value)
    {
        ArgumentNullException.ThrowIfNull(value);
        if (!LogValueText.IsValidUnicode(value))
        {
            throw new ArgumentException("Use valid Unicode scalar text.", nameof(value));
        }
        return new(LogValueKind.String, new(value));
    }

    /// <exception cref="ArgumentOutOfRangeException">value is NaN or infinite.</exception>
    public static LogValue Number(double value)
    {
        if (!double.IsFinite(value))
        {
            throw new ArgumentOutOfRangeException(nameof(value), "Use a finite floating-point number.");
        }
        return new(LogValueKind.Number, new(value));
    }

    /// <summary>Creates an integer within inclusive -9007199254740991 through 9007199254740991.</summary>
    /// <exception cref="ArgumentOutOfRangeException">value is outside the portable safe range.</exception>
    public static LogValue Integer(long value)
    {
        if (value < -MaximumSafeInteger || value > MaximumSafeInteger)
        {
            throw new ArgumentOutOfRangeException(nameof(value), "Use an integer within inclusive -9007199254740991 through 9007199254740991, or explicitly select IntegerString.");
        }
        return new(LogValueKind.Integer, new(value));
    }

    /// <remarks>No exponent, leading plus/zeros, whitespace or negative zero is accepted.</remarks>

    /// <remarks>A fractional part is required; trailing zeros and negative decimal zero are preserved.</remarks>
    /// <exception cref="ArgumentNullException">value is null.</exception>

    public static LogValue DecimalString(string value)
    {
        ArgumentNullException.ThrowIfNull(value);

            throw new ArgumentException("Use invariant decimal text with a fractional part and no exponent or leading zeros.", nameof(value));
        }
        return new(LogValueKind.DecimalString, new(value));
    }

    /// <summary>Creates a lowercase UUID string in hyphenated 8-4-4-4-12 form.</summary>
    /// <remarks>All Guid values, including Guid.Empty, are valid attribute scalars.</remarks>
    public static LogValue Uuid(Guid value) => new(LogValueKind.Uuid, new(value.ToString("D")));

    /// <summary>Creates a UTC timestamp with exactly seven fractional digits.</summary>
    /// <remarks>The supplied offset is converted to the same UTC instant; formatting is invariant.</remarks>
    public static LogValue Timestamp(DateTimeOffset value) => new(LogValueKind.Timestamp,

    /// <summary>Creates a bounded owned array, preserving input order.</summary>
    /// <remarks>The root counts as node/depth 1. At most 1024 nodes and depth 8 are retained.
    /// Copying stops after the first excess child; observed invalid children remain errors.</remarks>
    /// <exception cref="ArgumentNullException">items is null.</exception>
    /// <exception cref="ArgumentException">items contains a null reference instead of LogValue.Null().</exception>
    public static LogValue Array(IEnumerable<LogValue> items)
    {
        ArgumentNullException.ThrowIfNull(items);
        return new LogValueProjection().Array(items, depth: 1);
    }

    /// <summary>Creates a bounded owned ordinal map, preserving key text.</summary>
    /// <remarks>The root counts as node/depth 1. At most 1024 nodes and depth 8 are retained.
    /// Structural projection keeps the enumeration prefix and stops at the first excess child.
    /// Retained keys compare ordinally; observed invalid keys/children remain errors.</remarks>
    /// <exception cref="ArgumentNullException">properties is null.</exception>
    /// <exception cref="ArgumentException">A key is empty, malformed, contains controls, exceeds 255 scalars,
    /// occurs twice, or a value is a null reference instead of LogValue.Null().</exception>
    public static LogValue Map(IReadOnlyDictionary<string, LogValue> properties)
    {
        ArgumentNullException.ThrowIfNull(properties);
        return new LogValueProjection().Map(properties, depth: 1);
    }

    internal static LogValue OwnedArray(List<LogValue> items, bool truncated) =>
        new(LogValueKind.Array, array: items.AsReadOnly(), isTruncated: truncated);

    internal static LogValue OwnedMap(Dictionary<string, LogValue> properties, bool truncated) =>
        new(LogValueKind.Map, map: new(properties), isTruncated: truncated);

    private static (int Nodes, int Depth, bool Truncated) Measure(IEnumerable<LogValue> children)
    {
        int nodes = 1;
        int depth = 1;
        bool truncated = false;
        foreach (LogValue child in children)
        {
            nodes += child.NodeCount;
            depth = Math.Max(depth, child.Depth + 1);
            truncated |= child.IsTruncated;
        }
        return (nodes, depth, truncated);
    }
}

    private static readonly string LanguageRoot = Path.Combine(RepositoryRoot, "implementations", "csharp");

    [TestMethod]
    public async Task ReleaseCorePassesTheEvaluatedCompiledReferencePolicy()
    {
        string core = Path.Combine(LanguageRoot, "src", "CIS.Core", "bin", "Release", "net10.0", "CIS.Core.dll");
        ProcessResult result = await RunProjectCheck(LanguageRoot, "-AssemblyPath", core);
        Assert.AreEqual(0, result.ExitCode, result.StandardOutput + result.StandardError);
    }

    [TestMethod]
    [DataRow("CIS.Core.TestSupport")]
    [DataRow("Unapproved.Host.Infrastructure")]
    public async Task CompiledCheckerRejectsForeignAssemblyReferences(string dependencyName)
    {
        using var directory = new TemporaryDirectory();
        string fixture = Path.Combine(directory.Path, "CIS.Core.dll");
        WriteAssemblyFixture(fixture, dependencyName);
        string allowlist = Path.Combine(directory.Path, "allowed.json");
        File.WriteAllText(allowlist, "[\"System.Runtime\"]");
        string checker = Path.Combine(LanguageRoot, "eng", "CIS.DependencyChecker", "bin", "Release", "net10.0", "CIS.DependencyChecker.dll");

        ProcessResult result = await ProcessRunner.RunAsync("dotnet", [checker, fixture, allowlist], LanguageRoot, TimeSpan.FromSeconds(30));

        Assert.AreEqual(1, result.ExitCode);
        StringAssert.Contains(result.StandardError, "Unapproved compiled assembly reference");
        StringAssert.Contains(result.StandardError, dependencyName);
    }

    [TestMethod]
    [DataRow("ProjectReference", "../../../tests/CIS.Core.TestSupport/CIS.Core.TestSupport.csproj", "Forbidden project reference")]
    [DataRow("FrameworkReference", "Microsoft.AspNetCore.App", "Forbidden framework reference")]
    [DataRow("PackageReference", "Unapproved.Logger", "Unapproved explicit package")]
    public async Task EvaluatedCoreProjectRejectsForbiddenDependencies(string element, string dependency, string expectedRule)
    {
        using var fixture = new ProjectFixture(LanguageRoot);
        string coreProject = Path.Combine(fixture.Path, "src", "CIS.Core", "CIS.Core.csproj");
        XDocument project = XDocument.Load(coreProject);
        project.Root!.Add(new XElement("ItemGroup", new XElement(element, new XAttribute("Include", dependency))));
        project.Save(coreProject);

        ProcessResult result = await RunProjectCheck(fixture.Path);

        AssertRejected(result, expectedRule);
    }

    [TestMethod]
    public async Task ImportedProjectReferenceCannotBypassTheBoundary()
    {
        using var fixture = new ProjectFixture(LanguageRoot);
        string propsPath = Path.Combine(fixture.Path, "Directory.Build.props");
        XDocument props = XDocument.Load(propsPath);
        props.Root!.Add(new XElement("ItemGroup", new XElement("ProjectReference", new XAttribute("Include", "../../tests/CIS.Core.TestSupport/CIS.Core.TestSupport.csproj"))));
        props.Save(propsPath);

        AssertRejected(await RunProjectCheck(fixture.Path), "Forbidden project reference");
    }

    [TestMethod]
    [DataRow("Unapproved.Logger/1.0.0")]
    [DataRow("Microsoft.Extensions.Logging.Abstractions/10.0.999")]
    public async Task RestoredGraphRejectsUnapprovedIdentityOrVersion(string identity)
    {
        using var directory = new TemporaryDirectory();
        string assetsPath = Path.Combine(LanguageRoot, "src", "CIS.Core", "obj", "project.assets.json");
        JsonObject assets = JsonNode.Parse(File.ReadAllText(assetsPath))!.AsObject();
        assets["targets"]!["net10.0"]!.AsObject()[identity] = new JsonObject { ["type"] = "package" };
        string modified = Path.Combine(directory.Path, "project.assets.json");
        File.WriteAllText(modified, assets.ToJsonString());

        AssertRejected(await RunProjectCheck(LanguageRoot, "-AssetsPath", modified), "Unapproved shipping package dependency");
    }

    [TestMethod]
    public async Task PackageRejectsBundledTestAssembly()
    {
        using var directory = new TemporaryDirectory();
        string packagePath = Path.Combine(directory.Path, "fixture.nupkg");
        string core = Path.Combine(LanguageRoot, "src", "CIS.Core", "bin", "Release", "net10.0", "CIS.Core.dll");
        string packageVersion = System.Diagnostics.FileVersionInfo.GetVersionInfo(core).ProductVersion!.Split('+', 2)[0];
        File.Copy(Path.Combine(RepositoryRoot, ".artifacts", "csharp", "packages", $"CIS.Core.{packageVersion}.nupkg"), packagePath);
        using (ZipArchive archive = ZipFile.Open(packagePath, ZipArchiveMode.Update))
        {
            using var writer = new StreamWriter(archive.CreateEntry("lib/net10.0/CIS.Core.TestSupport.dll").Open());
            writer.Write("explicitly forbidden synthetic asset");
        }

        AssertRejected(await RunProjectCheck(LanguageRoot, "-PackagePath", packagePath), "Unexpected packed asset");
    }

    private static Task<ProcessResult> RunProjectCheck(string root, params string[] extraArguments)
    {
        string script = Path.Combine(LanguageRoot, "eng", "check-dependencies.ps1");
        string[] arguments = ["-NoProfile", "-File", script, "-LanguageRoot", root, "-ProjectPath", "src/CIS.Core/CIS.Core.csproj", .. extraArguments];
        return ProcessRunner.RunAsync("pwsh", arguments, root, TimeSpan.FromSeconds(60));
    }

    private static void AssertRejected(ProcessResult result, string expectedRule)
    {
        Assert.AreNotEqual(0, result.ExitCode, result.StandardOutput + result.StandardError);
        StringAssert.Contains(result.StandardError, expectedRule);
    }

    private static void WriteAssemblyFixture(string path, string dependencyName)
    {
        // A real managed PE fixture with an intentionally forbidden AssemblyRef; no shipping source is modified.
        var metadata = new MetadataBuilder();
        metadata.AddModule(0, metadata.GetOrAddString("CIS.Core.dll"), metadata.GetOrAddGuid(Guid.NewGuid()), default, default);
        metadata.AddAssembly(metadata.GetOrAddString("CIS.Core"), new Version(1, 0, 0, 0), default, default, (AssemblyFlags)0, AssemblyHashAlgorithm.None);
        metadata.AddAssemblyReference(metadata.GetOrAddString(dependencyName), new Version(1, 0, 0, 0), default, default, (AssemblyFlags)0, default);
        metadata.AddTypeDefinition(TypeAttributes.NotPublic, default, metadata.GetOrAddString("<Module>"), default, MetadataTokens.FieldDefinitionHandle(1), MetadataTokens.MethodDefinitionHandle(1));
        var builder = new ManagedPEBuilder(new PEHeaderBuilder(imageCharacteristics: Characteristics.ExecutableImage | Characteristics.Dll), new MetadataRootBuilder(metadata), new BlobBuilder());
        var image = new BlobBuilder();
        builder.Serialize(image);
        File.WriteAllBytes(path, image.ToArray());
    }

    private static string FindRepositoryRoot()
    {
        DirectoryInfo? directory = new(AppContext.BaseDirectory);
        while (directory is not null)
        {
            if (File.Exists(Path.Combine(directory.FullName, "implementations", "csharp", "CisLib.slnx")))
            {
                return directory.FullName;
            }

            directory = directory.Parent;
        }

        throw new DirectoryNotFoundException("Run the architecture tests from the CisLib checkout.");
    }
