# Event UTC time and W3C correlation (WP04-S04-T03)

EventProjection now owns a UTC DateTimeOffset and optional trace/span strings in CapturedEventFacts. It reads Activity.Current once, copies that activity's own W3C TraceId and SpanId, and accepts only exact lowercase hex lengths 32/16 with each ID nonzero. Missing, hierarchical or invalid activity produces neither ID. A zero trace with a nonzero current span is reachable through public .NET Activity; comparison against a default ID struct does not reliably detect an explicitly stored zero string. OperationId retains the separate event-over-scope rule. Nested free-form timestamp/trace_id/span_id/operation_id values cannot replace protected facts. Activity names, tags, baggage and links are not copied.

After severity/argument/name guards and reading the named DTO references, capture samples the pair before the clock or cooperative payload callbacks, then reads the clock once and normalizes its offset to UTC. TimeProvider.System is the default; an internal optional TimeProvider supports deterministic tests without retaining the provider. None returns before any clock/content read, and an undefined severity throws first. Invalid later payload can still read the clock and then fail; no admission occurs in this helper. This is a sequential capture, without a promised atomic snapshot against concurrent caller mutation. Captured time/IDs survive stopped/replaced activities, callback mutation and later reads; no Activity or clock is retained. The development observer formats UTC with seven fractional digits and Z; shipping escaped encoding and admission follow in T04 and later runtime tasks.

The [14 shared descriptors](../../../conformance/logging/event-correlation-cases.json) declare literal clock/protected-field expectations and explicit native bindings for randomly generated current IDs. A separate pre-capture Activity observation supplies binding values, independently checked for the selected scenario; expected IDs never come from the captured Core output. A supplied parent span is not the activity's current span. Unstarted/stopped Activity cannot be assigned as Current by the public CLR API and are recorded as no current activity. Eight additional native fault-injection rows deliberately modify private fields of pinned .NET 10.0.12 to exercise zero/short/uppercase/nonhex IDs; these are C# implementation controls, not public-API or portable scenarios.

Native tests also bracket the real system clock, mutate Activity and named inputs from clock/exception callbacks, collect source Activity/clock with facts alive, join barrier-driven inherited/suppressed child flows, and reject eight incorrect comparator outputs. The original CAPTURE-RESERVED-CORRELATION metadata/operation/attributes are preserved and exercised; its supplied 222 span binds to the parent span while the real generated current span is checked independently. Full literal wire-vector/structural qualification remains T05. Earlier T01/T02 observers deliberately keep their declared facts subset; they are not changed into full wire records.

T03 final native, Windows/Ubuntu, Claude and isolated-copy verification and commit are pending.
