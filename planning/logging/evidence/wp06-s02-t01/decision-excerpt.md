## WP06-S02-T01 borrowed host scope compatibility

Selected during implementation after read-only review identified host-scope loss amplification. This is a maintainer choice within the roadmap, not an additional user-quoted policy. Owned provider scopes remain strict: malformed or unsupported input throws to the creating caller. Borrowed host frames that raise ArgumentException during bounded copying are omitted as whole frames and mark the event truncated; the otherwise valid event remains eligible for admission. No arbitrary ToString or serializer is introduced. External-provider failures outside copy, non-argument copy failures, excess combined frame depth and invalid event state retain Core InvalidEvent behavior. Complete LoggerFactory/ActivityTrackingOptions integration remains WP06-S02-T05; the current HttpMethod case uses the real Microsoft external scope provider and BCL value, not a claim about an installed HttpClientFactory pipeline.
