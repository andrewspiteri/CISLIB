# Microsoft provider ownership

`CoreLoggerProvider(CoreLogRuntime)` always borrows the application runtime. `Dispose` is idempotent: it disables this provider's future logging calls and releases its borrowed external scope-source reference. It never stops or disposes Core, closes its file output, releases its file-group lease, or disposes a borrowed host scope source. There is no owning constructor option or extra lifecycle service.

The application finishes background work, explicitly calls `runtime.StopAsync`, observes the returned drain result, and disposes the runtime. Another provider over the same runtime and direct Core loggers remain usable after one provider is disposed. `DisposeAsync` joins Core's existing bounded shutdown. Complete host/factory shutdown ordering and concurrent flow qualification remain WP06-S02-T05; this task qualifies direct provider ownership.

A disposed provider returns false from its category loggers' `IsEnabled`; their valid `Log` calls perform no formatter or state capture. `CreateLogger`, `SetScopeProvider` and non-null `BeginScope` throw `ObjectDisposedException`. Existing argument guards still run in their documented order. A call already past the provider's disposal check can finish. Each such call retains the host scope-source reference it captured at entry; disposal does not interrupt its formatter or invalidate that source.

Owned `BeginScope` handles belong to the creating caller. Provider disposal does not pop their Core frames: direct logging observes them until the creator disposes the handles. LIFO checks and repeated valid disposal remain Core's existing rules. Host handles likewise stay with the host and remain active until it disposes them. See [scope capture](microsoft-provider-scopes.md) for layering and .NET child-flow detection limits.

The provider has no category cache, owned host scope source, timer, output worker or stream to close. Its disposed loggers/provider objects can still hold ordinary managed references to the borrowed runtime; the application must release its own references when finished. Clearing the external source reference does not promise a particular garbage-collection schedule. The reference-release test uses a non-inlined registration helper and explicit collections on the pinned managed .NET 10.0.12 qualification lanes; those operations are confined to the test fixture.

Four fresh-process public-runtime cases write actual physical JSONL. They prove direct/second-provider use and lease retention after provider disposal; creator-owned nested scope survival/LIFO cleanup; external source reference release without disposing that source; and a barrier-held formatter finishing with its original host scope after disposal. The application then stops Core, observes exact terminal counters and opens the released lease. The initial fixture incorrectly expected absent direct attributes; it was corrected to the schema-required empty object, without changing shipping behavior. Full story, candidate-package examples and release qualification remain pending.

using System.Security.Cryptography;
using System.Text;
using System.Text.Json.Nodes;
using CIS.Tests.DiscoveryFixture;
using CIS.TestSupport;
using Microsoft.VisualStudio.TestTools.UnitTesting;

namespace CIS.Tests.IntegrationTests;

[TestClass]
public sealed class ProviderOwnershipProcessTests
{
    public static IEnumerable<object[]> Modes => ProviderOwnershipExpectations.Modes.Select(mode => new object[] { mode });
    [TestMethod]
    [DynamicData(nameof(Modes))]
    public async Task ProviderDisposalLeavesApplicationRuntimeOwnership(string mode)
    {
        using var root = new TemporaryDirectory();
        var environment = System.Environment.GetEnvironmentVariables().Keys.Cast<string>()
            .Where(key => key.StartsWith("CORE_", StringComparison.Ordinal)).ToDictionary(key => key, _ => (string?)null, StringComparer.Ordinal);
        string host = Path.Combine(AppContext.BaseDirectory, "discovery-fixture", "CIS.Core.DiscoveryFixture.dll");
        ProcessResult child = await ProcessRunner.RunAsync("dotnet", ["exec", "--fx-version", "10.0.12", "--roll-forward", "Disable", host, "provider-ownership", mode, root.Path],
            root.Path, TimeSpan.FromSeconds(60), environment, new UTF8Encoding(false, true));
        Assert.AreEqual(0, child.ExitCode, child.StandardError); Assert.AreEqual("", child.StandardError);
        JsonObject report = JsonNode.Parse(child.StandardOutput)!.AsObject();
        Assert.AreEqual(Hash(host), report["fixtureSha256"]!.GetValue<string>());
        Assert.AreEqual(Hash(Path.Combine(Path.GetDirectoryName(host)!, "CIS.Core.dll")), report["coreSha256"]!.GetValue<string>());
        Assert.AreEqual(OperatingSystem.IsWindows() ? "windows" : "linux", report["os"]!.GetValue<string>());
        ProviderOwnershipExpectations.Validate(mode, report);
    }
    private static string Hash(string path) => Convert.ToHexStringLower(SHA256.HashData(File.ReadAllBytes(path)));
}

    private static void IncrementLossCounter(ref long counter)
    {
        long current = Interlocked.Read(ref counter);
        while (current != long.MaxValue)

            long observed = Interlocked.CompareExchange(ref counter, current + 1, current);

        }
    }

    {

        int accepted = 0;
        int interested = 0;
        foreach (Output output in outputs)
        {
            long? sequence = null;
            LogOutputWriteStatus status;
            if (!Interested(output, level))
            {
                output.Admission.RecordFiltered();
                status = LogOutputWriteStatus.Filtered;
            }
            else
            {
                interested++;
                if (output.Admission.IsFaulted)
                {
                    output.Admission.RecordUnavailable();
                    status = LogOutputWriteStatus.Faulted;
                }
                else if (output.Name == "console" && consoleLine is { } preparedLine)
                { status = queuedOutputs!.Console!.TryAdmit(captured, preparedLine, out sequence); }
                else if (output.Name == "file" && fileLine is { } preparedFileLine)
                { status = queuedOutputs!.File!.TryAdmit(captured, preparedFileLine, out sequence); }
                else { status = output.Admission.TryAdmit(captured, out sequence); }
                if (status == LogOutputWriteStatus.Accepted) { accepted++; }
            }
            if (Interested(output, level) && status is not (LogOutputWriteStatus.Accepted or LogOutputWriteStatus.QueueFull or LogOutputWriteStatus.Faulted))
            {
                throw new InvalidOperationException("Output admission returned an invalid status.");
            }
            if (status == LogOutputWriteStatus.Accepted ? sequence is null or <= 0 : sequence is not null)
            {
                throw new InvalidOperationException("Output admission returned an invalid ticket.");
            }
            observations.Add(new LogOutputWriteResult(output.Name, status, sequence));
        }
        LogWriteOutcome outcome = LogWriteOutcome.Rejected;
        if (accepted == interested) { outcome = LogWriteOutcome.Accepted; }
        else if (accepted > 0) { outcome = LogWriteOutcome.PartiallyAccepted; }
        return new LogWriteResult(outcome, observations, isTruncated: isTruncated);
    }

    {

        }

        if (!string.IsNullOrEmpty(operation) && !UnicodeScalarText.IsValid(operation, 255, allowControls: false)) { return "InvalidOperationId"; }
        // Arbitrary cooperative callback/unsupported payload failures expose only this fixed code.
        return "UnsupportedValue";
    }

namespace CIS.Logging.Scopes;

// One instance belongs to one future CoreLogRuntime; there is no process-wide scope slot.
// Runtime admission/closure and event capture are separate later integrations.
internal sealed class OperationScopeStore
{
    internal const int MaximumDepth = 32;
    private readonly AsyncLocal<OperationScopeFrame?> current = new();

    internal OperationScopeFrame? CurrentFrame => current.Value;

    internal CapturedScopeContext Capture() => CapturedScopeContext.FromHead(current.Value);

    internal IDisposable BeginScope(OperationContextData context)
    {
        ArgumentNullException.ThrowIfNull(context);
        return BeginCopiedScope(() => CapturedOperationContext.Capture(context));
    }

    internal IDisposable BeginCopiedScope(Func<CapturedOperationContext> capture)
    {
        OperationScopeFrame? parent = current.Value;
        if (parent?.Depth >= MaximumDepth)
        {
            throw new InvalidOperationException("The maximum operation scope depth is 32.");
        }
        CapturedOperationContext captured = capture();
        // A cooperative map enumerator may re-enter scope creation. Never overwrite its newer head.
        if (!ReferenceEquals(current.Value, parent))
        {
            throw new InvalidOperationException("Scope state changed during input capture.");
        }
        var frame = new OperationScopeFrame(captured, parent);
        var handle = new Handle(this, frame);
        current.Value = frame;
        return handle;
    }

    private sealed class Handle(OperationScopeStore owner, OperationScopeFrame frame) : IDisposable
    {
        // Idempotence state only: an inherited frame or this flag cannot identify a flow owner.
        private int disposed;

        public void Dispose()
        {
            OperationScopeFrame? active = owner.current.Value;
            if (ReferenceEquals(active, frame))
            {
                owner.current.Value = frame.Parent;
                Volatile.Write(ref disposed, 1);
                return;
            }
            for (OperationScopeFrame? ancestor = active; ancestor is not null; ancestor = ancestor.Parent)
            {
                if (ReferenceEquals(ancestor, frame))
                {
                    throw new InvalidOperationException("Dispose operation scopes in LIFO order.");
                }
            }
            if (Volatile.Read(ref disposed) == 0)
            {
                throw new InvalidOperationException("The operation scope is not active in the current asynchronous context.");
            }
        }
    }
}

                    Due = dueTime == Timeout.InfiniteTimeSpan ? long.MaxValue : clock.ticks + dueTime.Ticks; return true;
                }
            }
            private void BeginDispose()
            {
                if (Disposed) { return; }
                Disposed = true; clock.timers.Remove(this); clock.Disposed++; State = null;
                if (Running == 0) { Join.TrySetResult(); }
            }
            public void Dispose() { lock (clock.gate) { BeginDispose(); } }
            public async ValueTask DisposeAsync()
            {
                bool pending;
                lock (clock.gate)
                {
                    BeginDispose(); pending = !Join.Task.IsCompleted;
                    if (pending) { clock.PendingJoins++; }
                    clock.DisposalStarted.TrySetResult();
                }
                try { await Join.Task.ConfigureAwait(false); }
                finally { if (pending) { lock (clock.gate) { clock.PendingJoins--; } } }
            }
        }
    }
    internal static async Task Cleanup(CoreLogRuntime runtime, params Writer[] writers)
    {
        foreach (Writer writer in writers) { writer.ReleaseAll(); }
        runtime.CloseAdmission();
        try { await runtime.QueuedOutputs!.Completion.WaitAsync(Guard); } catch (IOException) { }
    }
