## Optional, not blocking
1. **The wrapper hides the inner message.** `BadImageFormatException` from "has no executable metadata" (a native PE selected explicitly) and from "is not an assembly" (a netmodule) both surface only as "invalid executable metadata". Consider appending `error.Message`, for example `...: {relativePath} ({error.Message})`. The current test string would still match as a prefix.
2. **README wording.** "Folder publish writes its own manifest" and "both folder-publish modes" could be read as covering FileSystem profiles generally. "CLI folder publish to `PublishDir`" would match the narrowed scope in the later paragraph.
3. **Case-sensitive matching.** `Select-String -CaseSensitive` would harden the now-specific matches. It's low value, because the strings are already distinctive.
4. **Stale files in `-o` directories.** These directories keep stale non-manifest files between runs. That can't cause a false pass, because the selected set comes from the freshly regenerated manifest. Removing the whole directory would still be cleaner evidence hygiene.
