## Repository and package foundation

- Separate CISLIB Git repository, organized for multiple modules and future language implementations under `implementations/<language>`.
- C# uses one `CIS.Core` assembly/package. Public namespaces start with `CIS`, including `CIS.Logging`, `CIS.Logging.MicrosoftLogger` and `CIS.TypeManagement`.
- Explicit version/signing/platform policies, pinned SDK/runtime/toolchain, central dependency versions and lockfiles.
- Two approved Microsoft runtime dependencies. Development tools have separate exact allowlists. Future integrations introducing third-party runtime dependencies, such as NLog, belong in separate packages.
- Shared contracts and conformance cases, native C# tests, compatibility baselines, documentation and verification entry points.
- CIS initialization and graph navigation are present. The latest recorded refresh has 11,009 nodes, 54,348 edges and zero diagnostics; its earlier persistence error did not recur. Build identity and bounded-query limits are retained in the [provider correction receipt](evidence/corrective-provider-map-boundary-2026-10-17/README.md). This is navigation evidence, not complete semantic/test coverage or a future graph-freshness guarantee.
