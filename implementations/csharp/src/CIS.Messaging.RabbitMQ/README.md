# CIS.Messaging.RabbitMQ

Optional RabbitMQ AMQP 0-9-1 transport for `CIS.Messaging`. Applications select
and provision their broker, trusted native identity profile and bounded topology
explicitly. Core consumers do not acquire RabbitMQ.Client or a database provider.

See the [provider guide](https://github.com/andrewspiteri/CISLIB/blob/main/docs/modules/messaging/rabbitmq.md)
and [module requirements](https://github.com/andrewspiteri/CISLIB/blob/main/planning/messaging/README.md).
A development package is not a published release or deployment qualification.
